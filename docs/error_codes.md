# 错误码参考

> **规范**: `SCH-XX-YYY` | **模块**: scheduler | **最后更新**: 2026-09-02

---

## 错误码结构

```
SCH - XX - YYY
 │    │    │
 │    │    └── 序号（001-999）
 │    └── 类别（00-99）
 └── 前缀（Scheduler）
```

---

## 错误码列表

### 00 成功

| 错误码 | 含义 | 说明 |
|-------|------|------|
| `SCH-00-000` | 成功 | 任务执行成功 |

### 01 配置错误

| 错误码 | 含义 | 说明 |
|-------|------|------|
| `SCH-01-001` | 配置文件未找到 | YAML 配置文件不存在 |
| `SCH-01-002` | 配置解析失败 | YAML 格式错误 |
| `SCH-01-003` | 配置校验失败 | 字段值不满足约束 |

### 02 注册错误

| 错误码 | 含义 | 说明 |
|-------|------|------|
| `SCH-02-001` | 任务名重复 | 已存在同名任务 |
| `SCH-02-002` | 任务未找到 | 指定的任务不存在 |
| `SCH-02-003` | 任务定义无效 | 必填字段缺失或格式错误 |

### 03 调度错误

| 错误码 | 含义 | 说明 |
|-------|------|------|
| `SCH-03-001` | 调度器启动失败 | APScheduler 初始化异常 |
| `SCH-03-002` | 调度器未运行 | 调度器尚未启动 |
| `SCH-03-003` | 触发器错误 | 触发器配置或执行异常 |

### 04 执行错误

| 错误码 | 含义 | 说明 |
|-------|------|------|
| `SCH-04-001` | 执行异常 | 任务函数执行失败（可重试） |
| `SCH-04-002` | 任务超时 | 执行时间超过 timeout 阈值 |
| `SCH-04-003` | 任务取消 | 任务被外部取消 |

### 05 幂等错误

| 错误码 | 含义 | 说明 |
|-------|------|------|
| `SCH-05-001` | 幂等冲突 | 相同幂等键正在执行 |
| `SCH-05-002` | 幂等重复 | 相同幂等键已完成（跳过） |

### 06 存储错误

| 错误码 | 含义 | 说明 |
|-------|------|------|
| `SCH-06-001` | 数据库连接失败 | SQLite 连接异常 |
| `SCH-06-002` | 存储操作失败 | SQL 执行异常 |

### 07 超时错误

| 错误码 | 含义 | 说明 |
|-------|------|------|
| `SCH-07-001` | 执行超时 | 线程/信号/进程级超时 |

### 08 告警错误

| 错误码 | 含义 | 说明 |
|-------|------|------|
| `SCH-08-001` | 告警发送失败 | 系统通知或 Webhook 失败 |

### 09 权限错误

| 错误码 | 含义 | 说明 |
|-------|------|------|
| `SCH-09-001` | 权限拒绝 | 访问受限资源 |

---

## 错误码使用示例

```python
from scheduler import TaskResult
from scheduler.models import ErrorCode

# 使用预定义错误码
result = TaskResult.fail(
    message="Database connection failed",
    error_code=ErrorCode.STORAGE_CONNECTION_FAILED,
)

# 使用自定义错误码
result = TaskResult.fail(
    message="Invalid input data",
    error_code="BIZ-001",  # 业务自定义
    skip_retry=True,
)
```
