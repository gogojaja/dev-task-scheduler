## 4. 接口分析（if）

### 4.1 外部接口清单

| 接口名称 | 方向 | 协议 | 认证 | 超时 | 降级策略 |
|---------|------|------|------|------|---------|
| Webhook 通知 | 出站 | HTTP POST | 无（URL only） | 30s | 通知失败不阻塞主流程 |

### 4.2 内部模块接口

| 模块 | 输入 | 输出 | 数据流 |
|-----|------|------|-------|
| registry | TaskDefinition/装饰器参数 | 注册到内部注册表 | 单向 |
| executor | 调度触发 | 执行任务函数 | 单向 |
| state_store | 任务状态 | SQLite 读写 | 单向 |
| record_writer | 执行记录 | CSV 追加写入 | 单向 |
| notifier | 告警事件 | 系统通知/Webhook | 单向 |

### 4.3 Python API 接口

| API | 参数 | 返回值 | 说明 |
|-----|------|-------|------|
| register_task | name/trigger/... | TaskDefinition | 装饰器注册 |
| get_scheduler | — | SchedulerManager | 获取调度器实例 |
| TaskResult.ok | message/data | TaskResult | 成功结果 |
| TaskResult.fail | message/skip_retry | TaskResult | 失败结果 |
| TaskContext.create | task_name/scheduled_time/params | TaskContext | 创建上下文 |

## 5. 数据要求分析（data）

### 5.1 核心数据实体

| 实体 | 关键字段 | 存储位置 | 说明 |
|-----|---------|---------|------|
| TaskDefinition | name/func_ref/trigger_type/trigger_config/max_retries/timeout/idempotency_key_expr | 内存+SQLite | 任务定义元数据 |
| ExecutionRecord | run_id/task_name/scheduled_time/start_time/end_time/duration/status/retry_count/idempotency_key/error_code | SQLite+CSV | 执行记录 |
| TaskResult | success/message/data/skip_retry/error_code | 内存 | 执行结果 |
| TaskContext | task_name/run_id/scheduled_time/start_time/retry_count/idempotency_key/params | 内存 | 执行上下文 |
| Config | scheduler/execution/recording/alerting 四域 | YAML 文件 | 运行配置 |

### 5.2 数据生命周期

| 阶段 | 数据操作 | 保留策略 |
|-----|---------|---------|
| 创建 | 任务注册→SQLite job 存储 | 永久 |
| 使用 | 调度触发→执行→状态更新 | 实时 |
| 归档 | 执行记录→CSV 台账追加 | 90 天自动清理 |
| 销毁 | SQLite 压缩/清理过期记录 | 配置控制 |

## 6. 安全分析（sec）

### 6.1 威胁建模（STRIDE）

| 威胁类型 | 适用性 | 风险等级 | 应对措施 |
|---------|-------|---------|---------|
| 欺骗 (Spoofing) | 低（本地框架） | 低 | 无需认证，本地信任 |
| 篡改 (Tampering) | 低（SQLite WAL） | 低 | 文件级 ACID |
| 否认 (Repudiation) | 中 | 中 | CSV 审计台账 |
| 信息泄露 (Info Disclosure) | 高 | **高** | 铁律 §3 A/B/C 级脱敏 |
| 拒绝服务 (DoS) | 低 | 低 | 超时控制+死信队列 |
| 权限提升 (Elevation) | 低 | 低 | 本地运行无权限提升面 |

### 6.2 安全控制点

| 控制点 | 措施 | 证据位置 |
|-------|------|---------|
| 敏感信息入库 | A 级禁止/B 级脱敏/C 级正常 | iron_rules §3 |
| 项目目录访问 | 26_访问边界.csv | 项目铁律 §1 |
| 高危操作留痕 | 13_安全审计台账.csv | iron_rules §3 |
| 密钥管理 | .secrets/gitignore+环境变量 | 项目铁律 |
